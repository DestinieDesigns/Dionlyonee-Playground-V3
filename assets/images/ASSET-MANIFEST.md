## Not generated / caveats
- **No AI image-generation tool was available in this environment.** All art is original, *procedurally drawn* pixel art (Python + Pillow) – not hand-painted or AI-rendered illustration. It follows the palette/art direction, but it is simpler than the reference image. If you want painterly storybook quality, treat these as production-ready placeholders/style baseline.
- Hero, 3 backgrounds, 4 banners, 6 portraits, 3 full-body, 17 thumbnails, 8 decorations and the logo were all produced. Nothing in the requested list was skipped.
- Full-body characters are transparent WebP (alpha). Decorations are transparent PNG (640×640 with padding so glows are never clipped; cloud/mist are 1024×512).
- Logo: `destinie-logo.svg` is a genuine vector (font glyph outlines converted to paths, no embedded raster); `destinie-logo.png` is rendered from it. Lettering uses Cinzel Decorative Bold (SIL OFL 1.1, © Natanael Gama), stored in `scripts/art/fonts/`.
- Thumbnails contain no text; themes are symbolic (wheel, bolt, grid of tiles, mic, curtains, emoji orbs, scroll, vinyl, lanterns, flame, podium, tiles, signpost, mirror, pedestals, potions).
- The reference-image PNG files were not available in the repo, so the art follows the described direction (moon, fox, lanterns, crystals, waterfalls, castles, violet/pink skies) and was not traced from them.
- Source code was **not** modified; existing images (`dionlyonee-pon-di-app.*`, `destinie-games-room.svg`) were not touched, so no backups were required.
